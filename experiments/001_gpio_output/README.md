# 实验 001：gpio_output 点灯

## 现象

黑盒行为规格：只描述外部可观察的行为，是烧录后的验收清单。

1. 上电复位后 LD1 **持续常亮**，不闪烁、不熄灭。
2. 无交互输入：行为与按键等外部事件无关（本实验没有输入通路）。
3. 可复现：同一固件重新烧录 / 复位后现象一致。

## 目的

体会**从寄存器完成对一个硬件 GPIO 的操作**——软件是因，物理世界是果。建立「寄存器控制 GPIO」的完整认知：

```text
RCC 门控时钟
  ↓
GPIO 寄存器配置（MODER / OTYPER / OSPEEDR / PUPDR）
  ↓
输出数据寄存器 ODR（状态存储：写什么就是什么）
  ↓
PB0 物理电平
  ↓
板载 LD1
```

认知点与验证：

- **RCC 门控**：外设不开时钟就不工作；使能后回读提供必要的同步延迟。
  验证（故障注入，可选）：注释掉 RCC 使能行，GPIOB 寄存器回读恒 0、写入无效。
- **ODR 是状态存储**：与 002 的 IDR「采样窗口」形成对照，这是读写两条通路的本质区别。
  验证：调试器中 ODR bit0 == 1；万用表 / 逻辑分析仪测 PB0 为高。
- **第一次跑通完整工程链路**：手册确认 → 寄存器编码 → 编译链接 → 产物分析 → 烧录（见 ROADMAP「001 的阶段目标」）。

伏笔：本实验主循环是空的（配置完即死等）；002 将让主循环第一次有了工作，并把数据流方向反转。
