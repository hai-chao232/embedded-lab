# 实验 002：gpio_input 按键轮询

## 现象

黑盒行为规格：只描述外部可观察的行为，是写代码前的契约、烧录后的验收清单。

1. **初始态**：上电复位后、未操作按键，LD1 保持**熄灭**。
2. **稳态映射**：**按住 B1 → LD1 亮；松开 B1 → LD1 灭**。是电平映射，不是「按一次翻转」——后者需要边沿检测，超出本实验范围。
3. **动态响应**：按下到亮、松开到灭的延迟**人眼不可察觉**（轮询循环周期远短于人的感知阈值）。
4. **边界现象（可能出现、必须能解释）**：快速点按时，LD1 可能在一次按压中出现**短暂闪烁 / 多次亮灭**——疑似机械触点抖动，见「目的 · 物理层」，不是功能缺陷。

第 1–3 条必须成立；第 4 条允许出现，且出现时要能解释。

## 目的

核心一句话：**把 001 的数据流方向反转**。001 里软件是因（写 ODR → 引脚电平 → 灯亮）；002 里外部世界第一次成为因（按键电平 → IDR → 软件只能观察），软件从「驱动者」变成「观察者」，再把观察结果反馈回输出侧。

认知链（与 001 的写通路对照）：

```text
001（写）：软件 → ODR → PB0 电平 → LD1          软件是因
002（读）：手指 → B1 → PC13 电平 → IDR 采样 → 软件轮询
           →（决策）→ BSRR/ODR → PB0 → LD1      世界是因
```

三层认知增量，每层挂一个可观察的验证：

- **寄存器层**：补全 GPIO 的读通路——MODER=00 输入模式；IDR 是**采样窗口**而不是状态存储：读到的只是读那一瞬间的电平，两次读之间发生的事永远丢失（对照 001 的 ODR：写什么就是什么）。写侧引入 BSRR 原子置位/复位，对照 ODR 的读改写。
  验证：调试器中观察 `GPIOC->IDR` bit13 随按下/松开实时变化。
- **架构层**：主循环第一次有了工作——`while(1){ 读输入 → 决策 → 写输出 }` 就是 Super Loop 的最小雏形（感知→决策→行动），也是一切嵌入式系统的最小骨架。亲身体会轮询的固有局限：**两次查询之间的事件不可见**。这是给 003 EXTI 预留的对照组：没有 002 的「CPU 空转查询」，003 的「事件驱动」就没有被解决的问题。
  验证：推理（或用逻辑分析仪实测）比轮询周期更短的按压脉冲会发生什么。
- **物理层**：第一次直面非理想物理输入。① 电平的确定性：松开时 PC13 为低，靠的是板载**外部下拉电阻 R58（220 kΩ）**，不是软件保证——所以内部上下拉可以不配；001 里随手配 00 的 PUPDR，这次要回答「为什么可以是 00」。② 机械抖动：板载消抖电容 C52 未贴片 → 没有硬件滤波，抖动会进入 IDR 的采样序列；轮询周期远短于抖动，软件基本能跟上它的多次跳变。现象 4 若出现，可作为现场证据。
  验证：快速点按观察闪烁；万用表/逻辑分析仪测松开时 PC13 的稳定低电平。

工程线附带验收（副产品，非主线认知）：002 是 E1 工程基线建成后的第一个新用户——「新实验只在顶层 `EXPERIMENTS` 加一行登记就能构建 + 烧录」这件事本身，就是对 E1 的验收。

刻意不做：不上中断（留给 003）、不写消抖状态机（把抖动留作可观察素材）。单实验单认知点。

## 硬件连接

![[artifacts\picture\B1_button.png]]

按键 USER(Blue) 接到 PC13 引脚（SB173 ON、SB180 OFF，板卡默认配置）。

高电平有效：按下为高电平，松开为低电平。

板级电路（已对照 ST 原厂 MB1137 B-01 原理图第 2 页及实物核实）：

```text
VDD ── B1 触点 ── 节点A
节点A ── R59 330Ω ── SB173 ── PC13
节点A ── R58 220kΩ ── GND        （外部下拉：松开时保证低电平）
节点A ── C52[N/A] ─ R60 100Ω ── VDD （未贴片，默认不生效）
```

- 松开时 PC13 由 R58 拉低，**无需配置内部下拉**；
- C52 未贴片（已对照实物确认）→ **板上无硬件消抖**。
